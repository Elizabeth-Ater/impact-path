ImpactPath — GCGO Advisor

An interactive quiz that helps incoming students discover which Global Citizenship & Goals pillar — Education, Health, Climate Change, or Women Empowerment — matches their interests, and recommends next steps.


Features

4 pages: Landing, Quiz, Results, Contact

Real-time form validation with custom regex

Timed 10-question quiz (30s/question, no going back), with an image hotspot, audio, and video question

Multi-category scoring engine with a speed/streak bonus

Animated Canvas radar chart + confetti on the Results page

Fully responsive, no backend — HTML5, CSS3, and vanilla JavaScript only
